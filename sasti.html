Tentang Saya

Mengenal latar belakang dan tujuan saya.

Saya merupakan mahasiswa Program Studi Sistem Informasi di Universitas Bina Sarana Informatika (UBSI) Tegal. Selain menempuh pendidikan, saya juga memiliki pengalaman kerja sebagai pramuniaga.

Pengalaman kerja membantu saya mengembangkan kemampuan komunikasi, pelayanan pelanggan, ketelitian, tanggung jawab, dan kerja sama tim.

Di bidang teknologi informasi, saya terus mempelajari basis data, SQL, pemrograman web, pengolahan data, dan analisis sistem informasi untuk meningkatkan keterampilan akademik maupun profesional.
